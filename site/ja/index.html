どのセッションが自分を待っているのか

セッションをいくつも開いていると、難しいのは「何をしているか」ではなく「どれが終わって自分を待っているか」です。

なぜ作ったのか

AI のコーディングセッションをいくつも回すと、手が空いて待たされるのは人のほうです。承認を待っているのがどの窓なのか、一つずつ切り替えて確かめることになります。

ファイルの更新時刻から推測すると、承認を待っているセッションも、時間のかかるシェルコマンドも、どちらも同じようにただ静かに見えてしまいます。

だから、各セッションが自分のために書き残しているファイルを読みます。推測はせず、書かれていることをそのまま見せます。

できること

  • メニューバーに数字ひとつ

    「2/5」— 待っているのが二つ、生きているのが五つ。セッションがいくつ増えても幅は伸びません。待っているものが無くなると、数字が静かに淡くなります。

  • 四つの状態を見分ける

    承認待ち・入力待ち・実行中・シェル実行。手が要る前の二つが、リストの上に上がってきます。

  • 四か所を一つのリストに

    ターミナルの Claude Code、Claude デスクトップアプリ、ターミナルの codex、ChatGPT アプリの codex スレッド。どこから来た行かは、名前を見れば分かります。

  • なぜ待っているのか

    行にマウスを載せると、何の承認を求めているのか、あるいは最後に何と言ったのかが表示されます。

  • クリックでその窓へ

    行をクリックすると、そのセッションが動いているターミナルの窓が前面に出ます（Terminal.app）。よく見る行は右クリックで上に固定できます。

  • 隅に置いておくパネル

    画面に余裕があれば、リストをデスクトップの隅に置いておけます。クリックしなくても見え、待っているものだけに絞ったり、最前面に置いたりできます。背景と濃さ、文字の大きさも選べます。

  • Mac 通知（既定はオフ）

    セッションが作業を終えたときと、承認を待ち始めたときに知らせます。通知を押すとそのセッションへ移り、そのタブを見ている間は鳴りません。見ているかどうかは Terminal.app でしか分からないので、ほかのターミナルでは常に鳴ります。

  • いくつのセッションまで回せるか

    待ちの列がどれだけ長かったかを、キーボードの前にいた時間だけ数えて記録します（--stats）。会話の内容は残さず、件数・時間・メモリだけを数えます。設定でオフにできます。

  • トークンの集計（既定はオフ）

    オンにすると、いまどれだけ埋まっているかと、始めてからどれだけ使ったかが見られます。サブエージェントの分も数えます。

画面

入手して開くまで

  1. Releases からダウンロードして解凍し、アプリを置いている場所へ移します。
  2. アプリを右クリックして「開く」を選びます。署名が無いため、初回だけ macOS が起動を止めます。一度で済みます。
  3. メニューバーに数字が出ます。セッションの行を初めてクリックしたときにターミナルの操作許可を求められたら、許可してください。

情報はどこへ行くのか

この Mac から出ません。セッションが手元に書き残しているファイルを読むだけで、読んだものをどこにも送りません。アカウントもサーバーもありません。

知っておいてほしいこと

  • 署名も公証もありません。配布用の署名には有料の Apple Developer アカウントが必要ですが、このプロジェクトにはありません。そのため初回だけ macOS が起動を止めます — 右クリックして開けば通れます。
  • macOS 専用で、ユニバーサル（Apple Silicon・Intel）です。macOS 13 SDK でビルドしていますが、実際に動かして確かめたのは macOS 26 だけです。
  • クリックでその窓へ行けるのは Terminal.app だけです。iTerm2・Ghostty・WezTerm・kitty では窓は動かず、その理由を表示します。tmux の中では窓までは行けますが、ペインまでは行けません。
  • Claude デスクトップアプリとターミナルの codex は状態を書き残さないため、記録の末尾から推定します。その行は測った値のふりをせず、推定だと告げます。

よくある質問

ソースは公開されていますか？

はい。MIT ライセンスで公開しています。

「開けません」「確認できません」と表示されます。

署名が無いためです。アプリを右クリックして「開く」を一度選んでください。それでも止められる場合は、システム設定 →「プライバシーとセキュリティ」の下のほうにある「このまま開く」を押してください。

ソースから自分でビルドできますか？

できます。Swift コンパイラがあれば、クローンして build.sh を実行するだけです。ほかの依存はありません。

Windows や Linux は？

いまは macOS 専用です。
